# Data structures Java

Java coursework implementing a binary search tree, doubly linked list, insertion sort, and quicksort.

Extracted from [ppv10/Projects](https://github.com/ppv10/Projects/tree/main/Data%20structures%20Java%20project%20(Finnish)). Assignment documents remain in the archive repository.

Compile an individual source file with `javac FileName.java`. The sort classes include small timing demonstrations.
